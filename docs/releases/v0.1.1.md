# RustPilot v0.1.1

RustPilot v0.1.1 menambahkan fondasi workflow developer yang lebih lengkap,
navigasi editor yang lebih cepat, dan pipeline release Windows otomatis.

## Highlights

- Startup splash menggunakan aset logo aplikasi.
- UI icons bergaya Material Design dengan warna state yang lebih jelas.
- Breadcrumbs dan Symbol Outline untuk navigasi fungsi, class, type, dan heading.
- Markdown Viewer dengan mode Code/Preview.
- Code folding, bracket highlight, dan indent rainbow per level.
- Klik file `M`/`U` di Project langsung membuka editor, bukan Working Tree diff.
- Fondasi Multi-Provider AI Agent untuk Claude, Codex/OpenAI, dan Antigravity.
- Tombol instalasi Claude SDK.
- Login Codex subscription melalui `codex login`.
- Fondasi SSH profile/session dan multiplexing pane seperti tmux.
- Tool window SSH mandiri dengan ikon khusus.
- GitHub Actions untuk build dan publish installer Windows saat tag dibuat.

## Perbaikan UX

- Panel Git tidak lagi terbuka otomatis saat startup.
- Posisi SSH berada di grup tool atas dan panel terpisah.
- Drag ikon tool dinonaktifkan agar sidebar tetap stabil.
- Garis indent abu-abu yang mengganggu dihapus.
- Badge Git tetap terlihat tanpa mengubah alur buka file.

## Catatan

- Adapter AI provider nyata masih bertahap; panel saat ini menyiapkan provider
  dan alur autentikasi.
- Transport SSH nyata, SFTP, port forwarding, dan LSP IntelliSense belum
  termasuk dalam rilis ini.
- Rilis ini menargetkan Windows 11.

## Instalasi

Unduh installer `.exe` dari bagian **Assets** pada GitHub Release.
