# RustPilot Feature Plans

These plans are intentionally small vertical slices. Each feature should ship
with its UI, tests, and one focused commit before the next plan starts.

Recommended order:

1. Command Palette
2. Quick Open
3. Recent Files and Projects
4. Autosave and Recovery
5. Find in Files
6. Tab Improvements
7. Multi-cursor Editing
8. Project Task Runner
9. Workspace Settings
10. Notifications Center
